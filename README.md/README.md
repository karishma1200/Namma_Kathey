# Namma Kathey

Namma Kathey is an Android application that showcases inspiring district hero stories from Karnataka.

## Features
- District-wise hero stories
- Kannada cultural storytelling
- Quiz section
- User-friendly Android UI
- JSON-based local data storage

## Tech Stack
- Kotlin
- Android Studio
- JSON
- XML Layouts

## How to Run
1. Clone the repository
2. Open in Android Studio
3. Sync Gradle
4. Run on emulator or Android device

## Future Improvements
- Firebase integration
- Audio storytelling
- Multi-language support
